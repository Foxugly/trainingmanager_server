# Training Manager — Deep Audit (2026-06)

Full read-only audit of both repos by a multi-agent pass:
- Backend: `trainingmanager_server` (Django 6.0 / DRF, PostgreSQL, ~855 tests)
- Frontend: `trainingmanager_frontend` (Angular 21 / PrimeNG / Transloco)

Overall the codebase is **high quality**: 100% OnPush, `@for track` everywhere,
disciplined owner/manager/athlete authorization, dashboard/stats already
de-N+1'd, fail-loud settings, throttling/Turnstile/RGPD. Items below are the
genuine gaps, prioritized. Status is tracked as items are addressed.

Legend: ☐ open · ☑ done · ⏸ deferred (with reason)

## P0 — security / data-integrity

- ☑ **Member create accepts arbitrary `user_id` (IDOR / account-linking).** Fixed:
  `perform_create` now requires the linked user to already belong to a team the
  caller manages (`member/views.py` `_require_user_in_managed_team`). Tests in
  `tests/test_member_create.py`.
- ☑ **RSVP → attendance bypasses the team-enabled-status invariant.** Fixed:
  `apply_to_attendance` resolves statuses from `team.attendance_statuses`; a
  non-enabled status is skipped. Regression test in `tests/test_rsvp.py`.
- ☑ **AI generate-training stamps Rounds with the wrong sport on multi-sport
  teams.** Fixed: stamps `event.sport or team.default_sport` (matches the
  generator). Regression test in `tests/test_ai_training.py`.
- ☑ **Unbounded bulk-attendance write.** Fixed: `MAX_BULK_ATTENDANCES = 500` cap
  in `AttendanceBulkSerializer`. Test in `tests/test_attendance.py`.
- ☑ **`RoundViewSet.clone`/`clone_exercise` no write-permission check / no
  `author`.** Fixed: both call `_require_may_mutate`; clone stamps `author`.
  IDOR regression test in `tests/test_lock_clone.py`.
- ☐ **Public-page toasts never render** (`<p-toast>` only in MainLayout) → no
  feedback on accept-invitation / language-switch errors. `public-layout.component.html`.
  *(frontend batch)*
- ☐ **Decide & document catalog sharing scope.** `Exercise`/`Round` reads are
  scoped by sport+language, not team → cross-team session contents readable.
  Mitigated for round *clone* (now team-gated, above); the *list/read* sharing
  model still needs a product decision. `round/views.py:32`, `exercise/views.py:198`.

## P1 — high value

Security
- ⏸ **JWT in `localStorage` → HttpOnly cookie.** Highest-value security change but
  a large, high-blast-radius auth refactor — deferred for review (not landed
  unattended). `token.storage.ts:9`.
- ☐ **No CSP header** (report-only to start). `settings/prod.py`.
- ☐ **Magic-link / password-reset tokens are replayable until expiry** (no
  single-use). `customuser/magic_link_token.py`.

Frontend UX / a11y
- ☐ Multi-tab form validation silently swallowed; switch to first invalid tab +
  `markAllAsTouched()`. `teams-form.component.ts:587`, `events-form.component.ts:378`.
- ☐ No unsaved-changes guard (`CanDeactivate`) on the big editors.
- ☐ Admin icon-only delete/restore buttons missing `ariaLabel`; no skip-link;
  nested `<main>` in the admin shell.

Perf / contract
- ☐ `event-print` N+1 (`1 + R + R×E` requests) — reuse embedded `rounds_detail`.
- ☐ Sentry tracing in the initial bundle — defer `browserTracingIntegration`.
- ☐ 32 endpoints `Observable<any>`; casts hide schema desyncs — add
  `@extend_schema(responses=)` + regen.

CI / ops / observability
- ☐ Backend deploy has no post-restart health-gate / rollback. `deploy/deploy.sh`.
- ☐ No OpenAPI schema-drift guard nor coverage floor in CI.
- ☐ AI spend has no budget alert.

## P2 — tech debt / polish

- ☐ Missing indexes: `Program (team, -updated_at)`; `audit.created_at` double-indexed;
  AI `Exercise.get_or_create` over 9 unindexed cols (+ race, no unique constraint).
- ☐ Duplicated admin CRUD ×4 (sports / energy-systems / segments / modalities).
- ☐ `effect()`-driven data fetch in 5 list components → `toObservable→switchMap`.
- ☐ `bleach` deprecated upstream → plan migration to `nh3`.
- ☐ `weekly_recaps` N+1 + not idempotent.
- ☐ Half-built dark mode; large smart components; `team.spec` flaky.
